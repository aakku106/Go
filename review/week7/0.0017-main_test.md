## Issues

### Critical

### Major

**1. Hardcoded Expected JSON**

```go
expected := `{"name":"Adarasha Gaihre","address":"Nepal","age":20}`
actual := string(response)
if actual != expected {
 t.Errorf("Expected %s, got %s", expected, actual)
}
```

String comparison of JSON is brittle. If encoding/json changes field order, test breaks even though JSON is equivalent. Should parse and compare structs:

```go
var expected, actual struct4
json.Unmarshal([]byte(`{"name":"Adarasha Gaihre","address":"Nepal","age":20}`), &expected)
json.Unmarshal(response, &actual)
if !reflect.DeepEqual(expected, actual) {
 t.Errorf("Expected %+v, got %+v", expected, actual)
}
```

Or use json.RawMessage comparison.

Appears in:

- TestMarshalPrivateFields
- TestMarshalWithStructTags
- TestMarshalWithProperTags

**2. TestUnmarshalUser Uses Fake Data**

```go
jsonData := `{
 "id": 1,
 "name": "Leanne Graham",
 "age": 25,
 "address": {
  "email": "leanne@example.com",
  "location": {
   "country": "USA",
   "province": "California",
   "city": "San Francisco",
   "tole": "Market St"
  }
 }
}`
```

This JSON matches the User struct defined in unMarsal.go. But unMarsal.go fetches from jsonplaceholder.typicode.com which returns **different structure**. Test passes because it uses hand-crafted JSON that matches struct, but real API calls will fail.

Test is testing "can we unmarshal JSON that matches our struct?" (yes, obviously). Should test "can we unmarshal the actual API response?" (no, struct doesn't match).

**Better test**:

```go
func TestUnmarshalRealAPI(t *testing.T) {
 // Actual jsonplaceholder response structure
 realJSON := `{
  "id": 1,
  "name": "Leanne Graham",
  "username": "Bret",
  "email": "Sincere@april.biz",
  "address": {
   "street": "Kulas Light",
   "suite": "Apt. 556",
   "city": "Gwenborough",
   "zipcode": "92998-3874",
   "geo": {"lat": "-37.3159", "lng": "81.1496"}
  }
 }`

 var user User
 err := json.Unmarshal([]byte(realJSON), &user)
 // This will succeed but most fields will be zero/empty
 // Test should verify this behavior
}
```

**4. TestMarshalPublicFields Complexity**

Lines 56-74:

```go
// Verify private field 'age' is not included
var result map[string]interface{}
if err := json.Unmarshal(response, &result); err != nil {
 t.Fatalf("Unmarshal failed: %v", err)
}
if _, exists := result["age"]; exists {
 t.Error("Private field 'age' should not be marshaled")
}
```

Unmarshals JSON into map to check field existence. This works but is overly complex. Simpler:

```go
actual := string(response)
if strings.Contains(actual, "age") {
 t.Error("Private field 'age' should not appear in JSON")
}
```

Or just check the exact string (which is already done in line 64).

