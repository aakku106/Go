## Issues

### Critical

**1. Every Error Ignored**

```go
json.NewDecoder(r.Body).Decode(&cat)  // Ignores error
id, _ := strconv.Atoi(r.PathValue("id"))  // Ignores error
cat, _ := CatCache[id]  // Ignores error
j, _ := json.Marshal(cat)  // Ignores error
```

**What happens when these fail?**

- Invalid JSON → `cat` is partially populated or zero-valued, gets stored anyway
- Invalid ID ("abc") → `id` becomes 0, always looks up cat 0 (doesn't exist)
- Cat not found → Returns empty JSON `{"catName":"","catAge":0}` instead of 404
- Marshal fails → `j` is nil, `w.Write(j)` writes nothing, client gets 200 OK with empty body

**This code lies to clients.** It returns 200 OK for errors.

**2. No Concurrency Safety**

```go
var CatCache = make(map[int]Cat)  // No mutex!

// In createCat:
CatCache[len(CatCache)+1] = cat  // RACE CONDITION!

// In getCat:
cat, _ := CatCache[id]  // RACE CONDITION!
```

Removed the sync.RWMutex from the original. If two requests happen simultaneously, this will crash with "concurrent map read and write" panic.

**Run this under load and it will crash immediately.**

**3. Same ID Bug as Original**

```go
CatCache[len(CatCache)+1] = cat  // len() doesn't track max ID
```

Still has the ID generation bug from try3_POST/main.go.

**4. No Validation**

```go
func createCat(w http.ResponseWriter, r *http.Request) {
    var cat Cat
    json.NewDecoder(r.Body).Decode(&cat)
```

Client can send:

All get stored with 204 No Content response.

## Recommendation for Week 5

Delete this file. If you want a "simple" example, write one that's simple AND correct:

```go
// simple_cat_api.go - Minimal correct POST/GET example
package main

import (
    "encoding/json"
    "log"
    "net/http"
    "strconv"
    "sync"
)

type Cat struct {
    Name string `json:"name"`
}

var (
    cats   = make(map[int]Cat)
    nextID = 1
    mu     sync.Mutex
)

func createCat(w http.ResponseWriter, r *http.Request) {
    var cat Cat
    if err := json.NewDecoder(r.Body).Decode(&cat); err != nil {
        http.Error(w, err.Error(), 400)
        return
    }

    mu.Lock()
    id := nextID
    nextID++
    cats[id] = cat
    mu.Unlock()

    w.WriteHeader(201)
    json.NewEncoder(w).Encode(map[string]int{"id": id})
}

func getCat(w http.ResponseWriter, r *http.Request) {
    id, _ := strconv.Atoi(r.PathValue("id"))

    mu.Lock()
    cat, ok := cats[id]
    mu.Unlock()

    if !ok {
        http.Error(w, "not found", 404)
        return
    }

    json.NewEncoder(w).Encode(cat)
}

func main() {
    mux := http.NewServeMux()
    mux.HandleFunc("POST /cat", createCat)
    mux.HandleFunc("GET /cat/{id}", getCat)
    log.Fatal(http.ListenAndServe(":8080", mux))
}
```

**This is 50 lines, simple, AND correct.** You don't need to break code to make it simple.
