## Issues

### Critical

**1. Nil Pointer Risk**

```go
fmt.Println("URL User Username: ", request.URL.User.Username())
```

If `request.URL.User` is `nil` (which it is for normal HTTP requests), this **panics**. URL.User is for URLs like `http://username:password@host/path` which are legacy and almost never used.

**Fix**:

```go
if request.URL.User != nil {
    fmt.Println("URL User Username:", request.URL.User.Username())
} else {
    fmt.Println("URL User Username: <none>")
}
```

**2. Complete Code Duplication**

`handleContact3` (lines 75-88) is **100% identical** to `handleRoot3` except it has one extra line (line 88: `fmt.Println("TLS", request.TLS)`).

This is code smell. If you want to print TLS, just add it to handleRoot3. Having two identical 13-line functions is wasteful.

**Fix**:

```go
func handleRoot3(writer http.ResponseWriter, request *http.Request) {
    // ... existing code ...
    fmt.Println("TLS:", request.TLS)

```

Delete handleContact3 entirely, or make it call handleRoot3.
