### Major

**1. Wrong Solution to Real Problem**

You have a legitimate issue:

> "I use TMUX and MAC so i never close my mac and tmux never kills my servers so i intensionally made this test file which autokills itself in ~600 sec"

**Correct solutions**:

**Option 1: Use context with timeout**

```go
func main() {
    ctx, cancel := context.WithTimeout(context.Background(), 10*time.Minute)
    defer cancel()

    server := &http.Server{Addr: ":8080"}
    go func() {
        <-ctx.Done()
        server.Shutdown(context.Background())
    }()

    server.ListenAndServe()
}
```

**Option 2: Signal handler**

```go
func main() {
    server := &http.Server{Addr: ":8080"}

    sig := make(chan os.Signal, 1)
    signal.Notify(sig, os.Interrupt, syscall.SIGTERM)

    go func() {
        <-sig
        server.Shutdown(context.Background())
    }()

    server.ListenAndServe()
}
```

**Option 3: tmux auto-kill**

```bash
# In .tmux.conf
set -g remain-on-exit off
set -g pane-died 'respawn-pane -k'
```

**Option 4: Makefile with timeout**

```makefile
run:
    timeout 10m go run main.go
```
