## Better Solutions

### Solution 1: Context with Timeout

```go
func TestServerWithAutoShutdown(t *testing.T) {
    server := &http.Server{Addr: ":8080"}

    // Auto-shutdown after 10 minutes
    ctx, cancel := context.WithTimeout(context.Background(), 10*time.Minute)
    defer cancel()

    go func() {
        if err := server.ListenAndServe(); err != http.ErrServerClosed {
            t.Errorf("Server error: %v", err)
        }
    }()

    <-ctx.Done()  // Wait for timeout
    server.Shutdown(context.Background())
}
```

This is the **correct** way to auto-shutdown.

## What Could Be Better

### 1. Make It an Actual Test

```go
func TestServerStartsSuccessfully(t *testing.T) {
    server := &http.Server{Addr: ":8080"}

    go func() {
        if err := server.ListenAndServe(); err != http.ErrServerClosed {
            t.Errorf("Server failed: %v", err)
        }
    }()

    time.Sleep(100 * time.Millisecond)  // Let server start

    // Test it actually works
    resp, err := http.Get("http://localhost:8080/")
    if err != nil {
        t.Fatalf("Server not responding: %v", err)
    }
    defer resp.Body.Close()

    if resp.StatusCode != 200 {
        t.Errorf("Expected 200, got %d", resp.StatusCode)
    }

    // Cleanup
    server.Shutdown(context.Background())
}
```

This actually **tests** the server.

if err := server.ListenAndServe(); err != nil {

At minimum, log the error.
