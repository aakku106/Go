## Issues

### Critical: Error Handling Still Missing

```go
server.ListenAndServe()  // Ignores error
```

**Week 5 review said**: "Add error handling to all HTTP files."  
**Week 6 reality**: Not fixed.

**Should be**:

```go
if err := server.ListenAndServe(); err != nil {
    log.Fatal(err)
}
```

### Major: Race Condition Remains

```go
var tem *template.Template  // Global variable

func handleCat(w http.ResponseWriter, r *http.Request) {
    tem = template.Must(template.ParseFiles("./htmlFiles/cat.html"))  // Concurrent writes
}
```

**Issue**: Multiple requests write to same global variable simultaneously.

**Week 5 review said**: "Parse templates once at startup."

**Should be**:

```go
var (
    catTem = template.Must(template.ParseFiles("./htmlFiles/cat.html"))
    dogTem = template.Must(template.ParseFiles("./htmlFiles/dog.html"))
)

func handleCat(w http.ResponseWriter, r *http.Request) {
    catTem.Execute(w, nil)  // Only execute, don't parse
}
```
