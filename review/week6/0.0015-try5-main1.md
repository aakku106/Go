## Issues

### Critical

**1. Broken Error Handling (handleContact)**

```go
if request.Method != http.MethodGet {
    http.Error(writer, "Method Not Allowed", http.StatusMethodNotAllowed)
}
// NO RETURN STATEMENT - CODE CONTINUES EXECUTING
```

http.Error sends response to client but doesn't stop function execution. You write error response, then continue processing and write more data. This creates malformed HTTP responses.

**Fix**:

```go
if request.Method != http.MethodGet {
    http.Error(writer, "Method Not Allowed", http.StatusMethodNotAllowed)
    return  // MUST return
}
```

**2. Duplicate Error Check**

Lines 90-93 check the exact same condition twice:

```go
if request.Method != http.MethodGet {
    http.Error(writer, "Method Not Allowed", http.StatusMethodNotAllowed)
}
if request.Method != http.MethodGet {  // EXACT DUPLICATE
    log.Println("Method Not allodwed here,", http.StatusMethodNotAllowed)
}
```

Should be:

```go
if request.Method != http.MethodGet {
    http.Error(writer, "Method Not Allowed", http.StatusMethodNotAllowed)
    log.Println("Method Not allowed:", request.Method)
    return
}
```

**3. Server Address Missing**

You set Addr correctly, but in earlier code (line 11) you print starting message before initializing server struct. No critical bug here, just noted.
