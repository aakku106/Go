```go

    log.Println("Error: ", err)
}
```

`ListenAndServeTLS()` requires two parameters:

```go
func (srv *Server) ListenAndServeTLS(certFile, keyFile string) error
```

You called it with **zero parameters**. This code **does not compile**.

Even if it compiled, you need actual certificate files:

```go
server.ListenAndServeTLS("cert.pem", "key.pem")
```

Without certificates, the server immediately fails:

```
Error: tls: failed to find any PEM data in certificate input
```

**This entire file is broken and cannot demonstrate TLS.**
