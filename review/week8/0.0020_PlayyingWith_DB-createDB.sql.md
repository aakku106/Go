# Code Review: 0.0020_PlayyingWith_DB/createDB.sql

**Rating: 4/10**

## Overview

SQL file with database creation command and SELECT query. 3 lines of SQL with unclear purpose.

## What This Code Does

Line 1: Creates database named "goFirst"
Line 3: Selects all rows from users table

## Issues

### Critical

1. **Wrong file type** - This is SQL, not Go code. Should not be reviewed under Go learning challenge
2. **Disconnected from main.go** - main.go connects to database "gofirst" (lowercase) but this creates "goFirst" (camelCase) - mismatch
3. **Not executable from code** - Go code in main.go doesn't run this .sql file. Purpose unclear
4. **Database already must exist** - main.go connection string specifies database "gofirst", but this file tries to create it - chicken and egg problem

### Major

1. **Missing semicolon** - Line 1 has no semicolon (works in some clients but inconsistent)
2. **No context** - No comments explaining when/how to run this file
3. **Case sensitivity** - "goFirst" vs "gofirst" in connection string - PostgreSQL defaults to lowercase
4. **Table doesn't exist yet** - Line 3 selects from users but users table is created in Go code, not here
5. **Mixed responsibilities** - CREATE DATABASE + SELECT query in same file is odd

### Minor

1. **Blank line** - Line 2 is empty, no separation needed for 2 commands
2. **No USE statement** - Doesn't switch to created database before SELECT
3. **No error handling** - No IF NOT EXISTS for database creation
4. **File naming** - "createDB.sql" suggests it creates database, but also has SELECT query
5. **Folder typo** - "PlayyingWith_DB" has extra 'y'

## What You Learned

Did not learn:

- How to execute .sql files from Go code

## Testing

## Final Verdict

**Orphaned SQL file with no clear purpose.** This file creates database "goFirst" but main.go connects to "gofirst" (different case). The SELECT query will fail because users table doesn't exist until Go code creates it. The file is not referenced or executed by any Go code.

**Likely scenario:** This was manually run in PostgreSQL client to create database before running Go code. But it's incomplete - should have:

1. CREATE DATABASE IF NOT EXISTS
2. \c goFirst (or \connect)
3. CREATE TABLE users... (not in Go code)
4. Initial seed data if

needed

**Purpose unclear:** Is this initialization script? Migration? Query scratch pad? No README or comment explains.

For SQL file in Go project, should either:

- Be executed by migration tool (golang-migrate, goose, etc.)
- Be embedded in Go code with embed package
- Have README explaining manual execution steps

Week 8 final week introducing database work is good. Having SQL file that doesn't integrate with Go code and has name mismatch (goFirst vs gofirst) is confusing.
